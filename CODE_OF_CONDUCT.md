# Code of conduct

SkillTrust talks about other people's work, so the bar for respect is high.

- Be kind and assume good faith, in issues, pull requests and discussions about any skill or its author.
- Criticise code and scores, not people. A low score says what a skill can do, not who its author is.
- No harassment, insults, personal attacks, or posting anyone's private information.
- Disagree with evidence: link to the code or the rule.

The maintainer, Vijaysinh Zala (GitHub: ZalaVijaysinh), may edit or remove comments and block people who break these rules. To report a problem privately, use the repository's Security tab (Report a vulnerability) and say it is a conduct report.
